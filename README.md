# Дом Радио — витрина форматов

Визуальная концепция: один концерт на разных носителях.

Афиша, квадратный анонс, история, баннер, сайт и городское размещение. Доступны фильтры и увеличение макетов. Открыть `index.html` локально или использовать GitHub Pages.

Исходная афиша предоставлена дизайнером. Квадрат, баннер и городское размещение — сгенерированные концепты. Витрина не является работающим движком и не содержит готовых файлов для печати.

Изображения и айдентика представлены для обсуждения проекта. Лицензия на их свободное использование не предоставляется.
