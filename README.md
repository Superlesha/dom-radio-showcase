# Дом Радио — система выпуска афиш

Единая страница предложения: задача команды, один концерт на разных носителях, сценарий графического дизайнера и проверки командой, правила дизайнера, форматы выдачи, варианты поставки и оплачиваемый пилот.

Афиша, квадратный анонс, история, баннер, сайт и городское размещение. Доступны фильтры, увеличение макетов и раскрывающиеся пояснения. Открыть `index.html` локально или [GitHub Pages](https://superlesha.github.io/dom-radio-showcase/).

Исходная афиша предоставлена дизайнером. Квадрат, баннер и городское размещение в галерее — сгенерированные концепты.

Отдельный технический образец позволяет изменить название, дату и участников, пересобрать две заданные композиции и скачать SVG с текстовыми объектами. Превью и скачивание используют один SVG. Временный шрифт Arial, RGB, без вылетов: образец не готовит файлы для печати и не реализует весь будущий движок. Слишком длинный текст блокирует выпуск соответствующего формата.

Проверено в Illustrator 28.1: 7 текстовых объектов в квадрате и 6 в баннере. Дата изменена с 21/06 19:00 на 22/06 20:00; AI сохранены и открыты повторно. Проверенные файлы находятся в `samples/`. Figma и печать пока не проверены.

Калькулятор использует только введённые пользователем значения. Они не отправляются на сервер и не сохраняются. Результат не гарантирует снижение денежных расходов. Команда, разбор афиши и критерии пилота дополняют предложение; портфолио ожидается.

Изображения и айдентика представлены для обсуждения проекта. Лицензия на их свободное использование не предоставляется.

Уточнение Q10: основной пользователь — графический дизайнер команды Дома Радио. После его проверки комплект передаётся пиару и продюсеру. Визитки и бейджи показаны как направление развития после пилота, а не готовая функция.
